==============================================================================
AVISOS DE TERCEROS - Imagen del frontend
==============================================================================

Este aviso cubre TODO lo que contiene la imagen del frontend: el servidor
web y sus modulos, los paquetes del sistema operativo de la capa base, y
el codigo de terceros de la aplicacion web que la imagen sirve.

El aviso de lo que efectivamente se envia al navegador, que es un
subconjunto, se publica aparte en notices/frontend-web.txt.

Generado por scripts/generar-avisos.mjs a partir de
notices/inventario/frontend-image.json. NO EDITAR A MANO.

El software de FCHMN es propietario y se distribuye bajo los terminos de su
propio archivo LICENSE. Los componentes que siguen son de terceros y se
rigen por las licencias que aqui se reproducen.

==============================================================================
TEXTOS DE LICENCIA  (26 licencias distintas)
==============================================================================

Un identificador no es un aviso. Alpine Linux NO incluye los textos de
licencia dentro de sus paquetes binarios, asi que se entregan aparte: el
directorio `licencias/`, junto a este archivo dentro de la imagen, contiene
el texto completo de cada licencia que obliga a entregarlo.

Origen de los textos canonicos: SPDX License List v3.29.0,
commit 31ba1a50e5397e00a304dbadc76531740e89ee48.

COMPONENTES CON COPYLEFT  (20 binarios)
------------------------------------------------------------------------------

Estos componentes obligan a poner a disposicion del destinatario la
fuente CORRESPONDIENTE a las versiones binarias entregadas, no una
version cualquiera ni un enlace generico que pueda caducar.

Estado actual: Todavia NO existe archivo de fuentes correspondiente ni oferta publicada. Este manifiesto no debe citarse como prueba de disponibilidad hasta que ese material exista.

Escenario: Las obligaciones de ofrecer fuente por distribucion externa no se activan todavia. Esto NO elimina las condiciones de atribucion: los avisos se incorporan igualmente, como politica conservadora de cumplimiento y para dejar el proyecto listo para una entrega externa futura.

Mecanismo previsto: Cada version publicada de las imagenes se acompanara de un archivo con la fuente correspondiente a ESAS versiones exactas: el APKBUILD y los parches de aports en el commit registrado aqui, mas los tarballs upstream que ese APKBUILD declara en `source=`.

Enlace LGPL: enlace dinamico contra bibliotecas compartidas del sistema. El destinatario puede sustituir la biblioteca reemplazando el objeto compartido dentro de la imagen. Esta condicion es la que hace admisible el enlace y se declara en el aviso.

Why Two Licenses?
=================

The zlib License could have been used instead of the Modified (3-clause) BSD
License, and since the IJG License effectively subsumes the distribution
conditions of the zlib License, this would have effectively placed
libjpeg-turbo binary distributions under the IJG License.  However, the IJG
License specifically refers to the Independent JPEG Group and does not extend
attribution and endorsement protections to other entities.  Thus, it was
desirable to choose a license that granted us the same protections for new code
that were granted to the IJG for code derived from their software.
